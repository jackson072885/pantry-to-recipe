# Repo Operations

This folder contains operating documents for repo hygiene, branch safety, local artifact cleanup, and repo structure.

These documents are meant to support safe, efficient work in the Pantry to Plate repository without wasting Codex usage on unnecessary ceremony.

## Files

### `codex-operating-rules.md`
Rules for branch safety, scope control, stop conditions, and efficient execution behavior for Codex-style work.

### `repo-hygiene-checklist.md`
A short repeatable checklist for staying clean before, during, and after repo work.

### `local-artifact-cleanup-policy.md`
Rules for what should stay local-only, what is safe to delete, and what should not be deleted casually.

### `repo-map.md`
A quick plain-English map of the repo structure and what the major areas are for.

## Usage

Use these docs when:
- preparing Codex prompts
- checking repo health
- cleaning local clutter
- deciding what should stay in source control
- reducing wasted output while preserving safety

These are repo-operation standards, separate from recipe-quality standards.
