## Friction Log

Capture concrete moments, not general opinions.

| Moment | What happened? | Severity |
| --- | --- | --- |
| First screen |  | P0 / P1 / P2 / P3 |
| Pantry entry |  | P0 / P1 / P2 / P3 |
| Best dinner option |  | P0 / P1 / P2 / P3 |
| Recommendation backup list |  | P0 / P1 / P2 / P3 |
| Recipe detail |  | P0 / P1 / P2 / P3 |
| Cook action |  | P0 / P1 / P2 / P3 |

Severity guide:

- `P0`: Blocks the tester from getting any dinner answer.
- `P1`: Produces a misleading or untrusted dinner answer.
- `P2`: Causes hesitation, but the tester can continue.
- `P3`: Polish issue that does not affect the dinner decision.
